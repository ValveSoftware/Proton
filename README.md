# Steamless Proton
Download Proton without Steam, or any other tools

## Why?
Because I like it

## Download
In Releases. Extract the contents to an empty folder. Points every software you need to run with it to ./files/bin.

## Build
Like the normal Proton. Or you can fork this and trigger the GitHub Actions. I use that way. It would take 2hrs to build, no hiccups.
